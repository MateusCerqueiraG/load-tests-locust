Demo Store API · gerado em 05/11/2026 18:51

✅ APROVADO

O sistema aguentou 50 usuários ao mesmo tempo por 30s. respondendo 670 ações com 0 falha(s) (0.00%) e tempo de resposta (p95) de 7 ms — dentro do limite de qualidade (SLA).

O que é um teste de carga? É simular muitos usuários usando o sistema ao mesmo tempo para descobrir se ele aguenta o tranco — se continua rápido e sem erros sob pressão, antes dos usuários reais chegarem. Abaixo, o resultado em números simples.

🧭 O que cada número quer dizer

  • Tempo de resposta — quanto o sistema demora pra responder. Menor = mais rápido (em ms, milésimos de segundo).
  • p95 — 95% das respostas foram mais rápidas que esse valor. Mostra como é a experiência no "pior caso comum", ignorando picos raros.
  • Vazão — quantas ações por segundo o sistema consegue atender. Maior = aguenta mais gente.
  • SLA — o "contrato de qualidade": metas que o sistema tem que cumprir (aqui: p95 abaixo de 500 ms e menos de 1.0% de erros). Se estourar, o teste reprova.
